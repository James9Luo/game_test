| # | 要做什么 | 为什么 | 数据/字段 |

| **3** | **连击保护 220ms**：第一次定格后 <220ms 的按下 → **不判定、不扣机会** | 玩家连点会把第二件用错误时机判掉 | `DESYNC_MIN_SECOND_MS = 220`（建议进 `modes.json`） |

### 1.1 渲染对齐口径（务必按这个来，否则"看到的≠判到的"）

```
贴图长边 = shape.size × laneScale     // laneScale：单物体 1.0，双物体 0.70
贴图旋转 = pose.rotDeg
贴图中心 = pose.x, pose.y
判定与绿框 = shape.pts（多边形，原样不动）
允许漂移 ≤ 1px；超过就是贴图切边/缩放口径不对
```

### 1.2 不需要动的地方

- 判定公式（轮廓重合面积 / 五档评级 / 星级）**一行没改**；
- 关卡窗口毫秒（`hit_target_ms`）**全部守恒**，`export_levels` 漂移季 1 ≤10.5%；
- 存档结构、图鉴解锁阈值、场景系统未变。

## 二、给美术（交付规格 + 新管线）

### 2.1 新管线（位图 → 多边形），四步

| 步 | 做什么 | 参数 |
| --- | --- | --- |
| 1 | 白底抠图，取主体 | 阈值 246，边界泛洪 |
| 2 | **膨胀 → 取最大连通 → 填洞 → 沿边串环** | 膨胀 5px（560px 画布） |
| 3 | **弧长均匀重采样**到 ≤80 顶点（不用 DP 删点，会自交） | 80 / 72 / 64 递减直到无自交 |
| 4 | 上色：逐色块按贴图 bbox 采样；底色 = 贴图**主色**；丢掉「面积大且亮度 0.42–0.58」的中间调 | 逐色压 L ≤ 78% |

工具：`03_交付素材/propkit_v10/`（`lookdev.py` / `trace.py` / `export.py` / `render.py`）。

### 2.2 交付规格

| 项 | 规格 |
| --- | --- |
| 贴图 | **256px**（长边）透明 PNG，白底已抠；另出 112px 版给原型 |
| 轮廓 | 单一闭合剪影、最细处 ≥ 宽 6%、无分离件（真要分离件用 `attach`） |
| 描边 | ≈ 长边 1.5–2%（不要写死 2px） |
| 颜色 | 同族 3–4 档硬边平涂；**不许渐变/alpha/光泽**；逐色 L ≤ 78% |
| 尺寸 | 长边归一化后按 `size` 出图；**只放大不缩小**，且只对点名件生效 |
