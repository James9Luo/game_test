01现状诊断：道具为什么"看着平"

数据源：assets/config/shapes.json（36 个判定轮廓，判定与绘制共用同一份 pts）。 渲染管线：原型/_src/game.js → drawObject()。下面每一个数字都是从真数据里量出来的，不是印象。

36现有道具（主线池 21 + 稀有池 15）
2.8平均装饰条数 / 件（0 条～4 条）
0渐变 / 阴影 / 高光层
4渲染层数：墨边 → 平涂 → 描边 → 装饰

绘制顺序（真代码）

  • ① 深墨外描边 4px → 只负责"从背景里抠出来"
  • ② 主体平涂 shape.fill → 一块纯色，无任何明暗
  • ③ 主描边 2px shape.stroke → 压暗两档的同色系
  • ④ 装饰 details 0–4 条 line / circle / poly → 只画不判

结论：一个道具 = 一块平涂 + 一圈描边 + 2.8 条线。所有"体积感"信息量为零， 所以 36 个道具看起来是同一套贴纸，不是 36 件东西。这不是画得不好，是渲染管线里没有"光"。

为什么不能直接加"阴影"

  • 绿框是唯一锚点（风格圣经 §3）：绿框描边 L=80%，任何比它更亮的元素都会抢焦点
  • 场景有 18pp 亮度预算（§7.2）：物体自身明暗不占场景预算，但局部提亮仍受 §6.1 约束
  • 物体在飞，不落地：局内加接地阴影 = 给一个空中物体造地面，读作 bug
  • 热力图叠在物体上：重/偏/空三区 α 叠加在物体上，物体自身明暗太碎会吃掉判定信息

结论：质感的落点必须是"物体自身内部"——顶光体积 + 边缘光 + 材质纹理， 而不是加投影、加光晕、加描边特效。

02质感方案：四层模型（物体自身内部）

每一层都必须满足三条硬约束：不改 pts（判定零影响）· 不出现在绿框外侧 · 局部 L 增幅 ≤ 8pp。 数据层复用现有 details 的 poly / line / circle，只用 #RRGGBBAA 追加 alpha， 零引擎契约改动；渲染层只在两处（原型 canvas / Cocos Graphics）各加一段。

L1 · 体积

顶光渐变：物体上缘 +18% 白，下缘 −26% 黑（source-over，不许 additive）。
内阴影：右下轮廓内侧一圈 2–4px 暗带，α ≤ 0.38。
作用：一块平涂变成一个"体"。

L2 · 边缘光

左上 1/3 弧段一条亮线（w 2–3px，α ≤ 0.5，色 = fill 提亮 45%）。
作用：在 noon_window 亮底（背景 L 94.6%）上把剪影从底色里"抠"出来—— 绿框在亮底只有 1.75:1，边缘光是对冲。

L3 · 材质纹理

按材质给 2–6 条专属特征：金属反光带 / 陶瓷高光斑 / 玻璃内层 / 木纹 / 叶脉 / 缝线 / 斑点 / 页边线。
作用：一眼看出"这是金属不是塑料"。这是道具库从"器物"变成"物品"的关键一层。

L4 · 接地

接触阴影 + 环境反射，只用在图鉴页 / 结算面板 / 首页静物，局内不加。
作用：图鉴里 36 格从"图标"变成"陈列品"，也让未解锁的灰剪影有实体感。

质感规范 12 条（美术交稿自检，程序落地对照）

① 判定零影响：任何质感层只能进 details，pts 一个字节都不许动。
② 描边不被吃掉：细节须内缩 ≥ 1px，主描边 2px 永远压在最上层。
③ 线宽下限：装饰线 ≥ 2px @1x（低于 2px 在 720 宽屏上会消失）。
④ 明度上限：高光叠加后局部 L ≤ fill 原 L + 8pp，且 ≤ 92%。
⑤ 锚点不被抢：物体任何像素不得比绿框描边（L 80%）更亮；琥珀亮档 #FFE066 例外值已记档。
⑥ 绿框独占：任何新增色不得进入 mint 色相 ±20° 区间（否则读成"这也是目标"）。
⑦ 细节密度：6–10 条 / 件（现状 2.8 条）；装饰总面积 ≤ 剪影 12%。
⑧ 剪影优先：缩到 96px 宽转灰度后仍能认出是什么（可辨识门槛）。
⑨ 热力图可读：物体自身明暗对比 ≤ 内部 30% 相对差，三区叠加后仍分得开。
⑩ 材质唯一：一件道具 1 主材质 + ≤1 副材质，禁止混搭出"金属木纹"。
⑪ 亮底可读：noon 场景下物体与背景对比 ≥ 1.7:1（靠暗描边 + 边缘光）。
⑫ 落地形态：纹理必须能用 poly / line / circle 画出来——不许依赖渐变贴图、不许引外部资源。

质感升级 · 验收清单

  • V1 判定回归：同一 pressMs，升级前后 pct 逐位相等（改的是 details，不是 pts）
  • V2 绿框回归：绿框 6px / #2BFFB0 / 位置 / 旋转一个字节不变
  • V3 亮度：逐像素扫道具区域，局部 L 增幅 ≤ 8pp，且无像素比绿框更亮（琥珀亮档除外）
  • V4 缩略可辨：道具缩到 96px 宽转灰度，5 人盲测 ≥4 人认得出
  • V5 描边完整：100% 素材目视，细节未压住 2px 主描边
  • V6 热力图：判定帧三区（重合/偏差/空缺）在有质感的物体上仍可分辨
  • V7 三场景：night / noon / minimal 下均不糊、不抢焦点（noon 额外查对比 ≥1.7:1）
  • V8 低画质：质感强度降到 0 时仍可玩（低画质只留 L1 顶光 + 主描边）
