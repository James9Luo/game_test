# 交付说明 · 《定格瞬间》 v0.1.1（垂直切片 + relax 音频版）

> 2026-10-18 · 主策划 · 本文件是「怎么用、怎么验、验到什么程度」的唯一入口。

## 1. 现在就能玩（30 秒）

**双击** `原型/dista_prototype.html`（单文件 193.5 KB、无依赖、离线可用）。

| 你要做的 | 结果 |
| --- | --- |
| 点【开始】 | **从第 1 关开始**（不是从存档那一关；这是 v0.1.1 修掉的 bug） |
| 等物体转到绿框里 | 点任意处 → 当帧冻结 |
| 看结算 | 评级 / 重合率 / **按早或按晚多少 ms、少转或多转多少度** / 得分 / 星级 |
| 失败 | 0.7 秒后自动重来；一关 3 次机会 |

**调试入口**（截图与验收用）：
`?screen=play&lvl=5&press=0.57` · `?screen=result&lvl=1&press=0.515&fxAt=400` · `?screen=home&progress=6&tap=start`
`press` = 在周期哪个比例按下（`0.5` = 完美时机）；`fxAt` = 把特效时钟冻结在按下后 N 毫秒；`tap` = 模拟点首页按钮；`diag=1` = 叠层显示内部状态。

## 1.1 v0.1.1 新增：音乐与放松调性

| 项 | 说明 |
| --- | --- |
| 背景音乐 | 64 BPM / D 大调五声 / `Dmaj7–A–Bm7–Gmaj7` / 8 小节 30 秒循环；pad + 毡音拨弦 + 低音 + 沙锤 + 反馈延迟混响 |
| 五档特效音 | 神级 `D5→F#5→A5→D6`、完美 `A4→D5→F#5`、不错 `D5→A5`、及格单音 `D5`、失败 `D3+F#3`——**全部同一个五声音阶**，这就是"协调"的硬保证 |
| 定格手感 | 按下那一帧**风声硬切为 0**（不是淡出）。"静音"本身就是定格成功的反馈 |
| 动画 | 柔光呼吸替代全屏闪白；神级 3 环 + 24 颗微尘（沿绿框周长采样）、完美 1 环 + 12 颗、不错绿框呼吸、及格极淡一环、失败只把物体降到 65% 不透明度（**不抖屏、不红闪**） |
| 静音 | 右上角图标（视觉 44px / 热区 88px），状态存本地，默认开 |

**想先听再玩**：`03_交付素材/audio/` 里有 `bgm_loop.wav`（30 秒循环）与 5 个 `sfx_*.wav`，双击即可播放。
这些 WAV 不是另录的一份——**和游戏里播放的是同一份音符数据**（`原型/_src/audio.js` 一套 events、两个渲染器），所以试听等于试玩的声音。

**重开规则**：

| 入口 | 行为 |
| --- | --- |
| 首页「开始」 | **永远第 1 关** |
| 首页「继续 · 第 N 关」 | 仅当进度 > 1 时出现 |
| 结算「重试本关」 | 同关卡号重来 |
| 通关页「再玩一次」 | 回第 1 关 |

回归证据：`04_项目管理/验收截图/proto_tap_start.png`（进度 6 → 点开始 → **第 1/15 关**）、`proto_tap_continue.png`（→ **第 6/15 关**）。

## 1.2 v0.2/v0.3：双模式 + 三场景 + 日夜自适应

首页两个入口。**两个模式的判定、评级、星级、分数、连击、特效、音效、HUD 完全相同（就是第一版）**；唯一差异是**有没有时间限制**（v0.3 修正，v0.2 曾误把放松模式做成"不计分/不判失败"，已作废）：

| 维度 | 闯关挑战 | 催眠放松 |
| --- | --- | --- |
| **每关时限** | **15 秒倒计时**，超时＝本关失败 | **无时限** |
| 每关机会 | 3 次 | 3 次 |
| 关卡 | 15 关打完 → **结算（本局总分 + 历史最高分）** | 15 关打完 → **回第 1 关继续**（记轮次） |
| 判定/评级/分数/星级 | 完全同 v1 | 完全同 v1 |
| 动画/音效 | 五档分级 + 五档评级音 | 完全同 v1 |
| HUD | 关卡/次数/连击/得分/**倒计时** | 关卡/次数/连击/得分（无倒计时） |

- **倒计时**：从本关第一次物体进场起算；结算出现即停表；重试重置为 15 秒；≤3 秒时数字转琥珀并轻微呼吸（不用红、不闪、不震）。
- **最高分只在挑战模式记录**（`localStorage.bestScore`）。催眠模式不参与排名——助眠玩家不该被分数绑架。
- **首页主次**：主按钮「闯关挑战 · 15 关」（实心），次按钮「催眠放松 · 无倒计时」（描边）。

**三场景**（美术产出 `assets/config/scenes.json`，程序只读）：

| id | 名称 | 底色 | 动态层 | 周期 |
| --- | --- | --- | --- | --- |
| `night_station` | 深夜候车 | `#0B1424 → #111E33` | 柔云 2 层 + 远处车灯平移 + 星点 | ≥18s |
| `noon_window` | 午休窗边 | `#EDE6D8 → #E8EEF4` | 窗格光斑 3 个 + 窗帘微动 | ≥14s |
| `minimal` | 极简纯净 | `#141A24 → #0E1420` | 细碎粒子 16 个 | ≥30s |

- **日夜自适应**：本地 07:00–18:59 → `noon_window`；19:00–06:59 → `night_station`；`minimal` 仅手动。
- **手动优先**：手动选择存 `localStorage['dista.scene']`，优先于自动；只在关卡之间切换（不在判定帧突变）。
- **亮度预算**：装饰层叠加 ≤ 背景 **+18 个百分点**（实测 night +13.4 / noon +1.3 / minimal +5.1）。
- **浅底可辨识**：绿框在 `noon_window` 用「1px 硬边 + 色相差 118°」，不再要求 WCAG 4.5:1（D-042 有推导）。

**物体分层**（23 个形状，均过 k 门禁）：

- tier2（中段）`guitar` `wrench` `rocket` `tv` `skateboard` `camera` `handheld` `dessert`
- tier3（高阶/传播）`octopus` `cat` `duck` `burger` `toilet` `banana` `hammer` `crab` `mecha_doll`

## 3. 怎么验（复制即用）

```powershell
cd E:\game_design\dista
$node = 'C:\Users\Administrator\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe'

& $node tools\export_levels.mjs      # CSV → JSON（含命中窗口）+ shapes 同步   期望 PASS 7/FAIL 0
& $node tools\geometry_test.mjs      # 判定几何回归                              期望 PASS 198/FAIL 0
& $node tools\shapes_check.mjs       # 15 个轮廓合法性                            期望 ALL GREEN
& $node tools\sim.mjs --n=10000      # 难度曲线模拟（约 110 秒）                 期望 L1≈74%/窗口单调
& $node tools\build_proto.mjs        # 构建单文件原型                            期望 <200KB
& $node tools\audio_check.mjs        # 音频 A1–A10 + 重开/静音/无音频降级         期望 PASS
& $node tools\render_audio.mjs       # 离线渲染 8 个 WAV + 峰值/RMS/调式检查
powershell -ExecutionPolicy Bypass -File tools\verify_proto.ps1   # 13 截图 + 4 DOM + 自测 + 音频
```

**改数值的唯一正确路径**：改 `01_策划文档/levels.csv` → 重跑 `export_levels.mjs` → 跑 `sim.mjs` 看曲线。**不许改 ts 里的数字。**

**改观感的路径**：`原型/_src/audio.js`（音色/包络）+ `game.js` 里的 `RING_CFG` / `MOTE_CFG` / `HEAT_STYLE` 三张常量表。**判分口径一行不动。**

## 4. 本机环境限制（别当成 bug）

| 限制 | 影响 | 绕过 |
| --- | --- | --- |
| 无 Cocos Creator | 场景/预制体无法生成 | Cocos 层做成「空场景挂 Boot，全代码建节点」；见 `客户端_接入说明.md` |
| 无 tsc / 编辑器 | `cc` 类型无法验证 | 做了可擦除语法体检（10/10 过）；8 条不确定 API 带替代方案 |
| 子会话 shell 不可用 | 队友只能写不能跑 | 实测由 lead 代跑，结果回填各角色文档 |
| **PowerShell 5.1 按 ANSI 读 UTF-8** | 用 `Get-Content | Set-Content` 重写含中文的文件会**毁编码** | **文档一律用编辑器写工具改，禁止管道重写**（D-037） |
| 验收截图是 680×1149 / 0.9 缩放 | 量图像素 ≠ 设计像素 | `x_design=(x_shot−16.8)/0.9`，或看 `?diag=1` 的 `view/scale/ox` |

## 7. 关键数字速查（被问到时直接答）

| 问题 | 答案 |
| --- | --- |
| 判定是什么 | `重合率 = 交集面积 / max(物体面积, 目标面积)`，扫描线精确积分，**不是中心点距离** |
| 一次性判定多快 | 0.0423ms（20 顶点 × 2 物体）；48 顶点×2 物体 0.111ms；红线 0.5ms |
| 第一关难不难 | 新手档通关率 **74.1%**（目标 60–85%） |
| 高光有多稀有 | 熟练档 12.8%、顶级档 36.6%（原「2–5%」不成立，见 D-015） |
| 难度靠什么 | **命中窗口**（140ms → 36ms 单调收窄），不是"物体更快" |
| 一关最多几个难度变量 | 2 个（速度 / 形状敏感度），扰动与变速各只在一处引入 |
| 音乐为什么"协调" | 全部 D 大调五声 `{D,E,F#,A,B}` + 3 种波形族 + 同一反馈延迟；机器已验音名全部在调内 |
| 15 关都能玩吗 | 能，原型里全通；Cocos 层待编辑器验证 |
