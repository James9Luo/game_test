## 2. 重拍时发现并修掉的三件事

### 2.1 图鉴里没有细节（真问题，已修）

**现象**：`drawGallery()` 只画 `pts` + `fill` —— 格子里全是平涂剪影。新道具的"分层"在图鉴里一点看不见，等于白做。
**修法**：新增 `drawDetailsWorld(shape, cx, cy, rot, k)`（建 transform 后复用 `drawDetails`），图鉴格（100px）与 240px 详情在**已点亮**时补画 details；未点亮仍是灰剪影（v0.9 §3.2 不变）。
**线宽**：`drawDetails` 增加 `wScale` 参数。details 的 `w` 是设计 px（size≈250），图鉴 100px 显示时必须按 `k/size` 等比缩，否则 3.2px 的线在格子里相当于 8px（会把物体糊死）。
**验证**：`proto_gallery_p1.png` 里小汽车有窗和轮、可乐罐有标签带、吉他有音孔与品丝、火箭有舷窗与尾翼。

### 2.2 验收脚本会挂死（D-108 的欠账，已补）

**现象**：`verify_proto.ps1` 用 `& $Edge …` 直接调用，Edge 不退出时整条流水线卡在 DOM 检查（上次跑到 6/7 就没有下文，留下 35 个 headless 进程）。
**修法**：抽 `Invoke-Edge`（`Start-Process` + `WaitForExit(timeout)` + `taskkill /T /F`）。截图超时 **90s**、DOM **45s**——先按 30s 试，结果 `proto_desync` / `proto_god_diag` 两个状态在 Edge 里要跑 60–120s 才出图，30s 会误杀（实测直接跑能出 377KB / 403KB 的图）。
**验证**：整条流水线 7 步跑完不再挂；只有这两个慢状态触发重试。

### 2.3 `build_proto` 的假警告（已修）

**现象**：每次构建都报 36 条 `shape[x]: 最长边 … 未归一化到 1±2%`。
**根因**：那行代码算的是「最长**单条边**」（相邻两点距离），不是包围盒长边；任何多边形都不可能接近 1。
**修法**：改成包围盒长边（与 `check_shapes.longSideOf` 同口径）→ 构建输出 0 条误报。

## 3. 基线怎么用（以后）

```powershell
# 1) 重建 + 重拍（会覆盖上面的 43 张）
powershell -ExecutionPolicy Bypass -File tools\verify_proto.ps1

# 2) 重写基线清单
python temp\make_manifest.py     # 或把这段逻辑并进 verify_proto

# 3) 比对：与 _manifest.json 的 sha256 比，差异必须能解释
```
> 规矩：**截图差异不能"看着差不多就放过"**。改了视野/缩放/主题/道具数据，差异必须能在本文件或决策记录里找到对应条目。
