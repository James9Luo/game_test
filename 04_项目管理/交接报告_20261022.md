## 三、现在这套管线的标准动作（以后换道具照跑）

```bash
# 1) 描样（生成图 → 多边形）     见 03_交付素材/propkit_v10/lookdev.py + trace.py
# 2) 落库到 assets/config/shapes.json（两份：config + resources）
# 3) 窗口归位（形状一变必跑！）
node tools/refit_cycles.mjs --apply
# 4) 图鉴 k/难度档同步
node tools/update_collection_k.mjs --apply
# 5) 验收四连
node tools/shapes_check.mjs
node tools/export_levels.mjs
node tools/build_proto.mjs
node tools/modes_check.mjs --write-win-baseline && node tools/modes_check.mjs
```

**铁律**：判定吃 `pts`（重合面积）；`details` / `attach` 只影响观感；**任何形状/尺寸/车道改动都必须跑第 3 步**，否则等于偷偷改难度。
