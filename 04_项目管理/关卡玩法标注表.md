### 「同类最近间隔」的算法（可以拿笔验算）

1. 取该类标签的**关号**（不是季内序号、不是发布时间），从小到大排序，如 `正弦摆动 = [16,19,22,28,49]`。
2. 相邻两项相减得间隔序列：`3, 3, 6, 21`。
3. **最近间隔 = 间隔序列的最小值**（= 该类在流程里最密集的重复节拍）；上表另给「出现在哪一对」便于回查。
4. 只看**同类**（跨类间隔不算，例如「惯性→提速」不计入任何一格）。
5. 单关类不存在，故无 `—` 行；若以后某类只剩 1 关，间隔记 `—`。

> 读法：间隔越小 = 该机制在流程里越「连着来」。`双轮廓` 每 5 关一次（10/15/20/25/30）是季 1–2 的固定节拍；`错拍` 间隔 10 关（L50→L60）说明它只在季 4 中段与压轴各出现一次，中间留给「综合」关——这是有意的：错拍是最终考核，不连考。

| 季 | 基础·旋转 | 提速 | 双轮廓 | 正弦摆动 | 变速 | 惯性 | 错拍·双物体 | 机制·综合 | 合计 |
|---|---|---|---|---|---|---|---|---|---|

| 2 | 0 | 8 | 3 | 4 | 0 | 0 | 0 | 0 | 15 |
| 3 | 0 | 8 | 0 | 0 | 0 | 4 | 0 | 3 | 15 |

三条可直接用于排期/复盘的事实：

- **每季稳定 8 关「提速」做节奏骨架**（S2/S3/S4 各 8 关，占该季 53%）。它们的职责不是教新东西，而是把上一关的机制在更高速度下再考一次——所以 HUD 显示「提速」时要带上一句话玩法，否则玩家会觉得「又是这关」。

## 4. 数据不一致（关号 + 两个值 + 判断 + 理由）

### D1｜`lin_speed_min/max`：CSV 与 JSON **60/60 关全部不一致**（严重）

| 关 | CSV `lin_speed_min/max` | JSON `linSpeed[0]/[1]` | angSpeed（两侧） |
|---|---|---|---|
| 1 | 286 / 286 | 333.8 / 333.8 | 111.3 / 111.3（一致） |
| 10 | 660 / 660 | 604 / 604 | 402.7 / 402.7（一致） |
| 16 | **0 / 0** | 471.3 / 510.5 | 321 / 334（一致） |
| 21 | **1 / 1** | 533.6 / 533.6 | 一致 |
| 59 | **1 / 1** | 1414.5 / 1414.5 | 一致 |

- 形态：**L1–15** CSV 是 258–660 的旧实测值（与 JSON 差 −14% ~ +76%）；**L16–60** CSV 写的是 `0` 或 `1`（占位/未填），而 JSON 是 471–1414。
- **以 JSON 为准**。理由三条：① `levels.json` 的 note 明写「linSpeed/angSpeed 为派生字段（工具重算，运行时只读）」；② `angSpeed` 两侧 60/60 完全一致，说明真源是角速度，线速度是按形状半径派生的量；③ JSON 的 `linSpeed/angSpeed` 比值随形状变化（L1 3.00、L3 1.50），符合「线速度 = 角速度 × 半径」的物理关系，CSV 的 0/1 无法解释。
- 对本表影响：**零**（本表不引用线速度）。对流程的影响：`levels.csv` 自称唯一真源，但这两列已失效——建议二选一，见 §7-2。

### D2｜`time_limit_sec`：CSV 空串（58 关）vs JSON `0`（58 关）

| 关 | CSV | JSON | 运行时实际 |
|---|---|---|---|
| 1–49、51–59（58 关） | 空（`""`） | `0` | 挑战模式取 `modes.json` 的 15000ms |
| 50、60 | `20` | `20`（一致） | 20s（单关覆盖） |

- **以 CSV 的「空 = 不覆盖」语义为准，JSON 的 `0` 是归一化结果**。理由：原型 `levelTimeLimit(def)` 的实现是 `if (def && def.timeLimitSec) return def.timeLimitSec*1000; return cfg.timeLimitMs;`——`0` 和空走同一分支，都是回落到 15000ms，两者行为等价。
- 风险：只是口径歧义，不是错值。但**若后续有人把「0 秒」理解成「不计时」**，会改错。建议 CSV 统一写 `0` 并在表头注明「0 = 不覆盖，回落 15s」。

### D3｜同号关羽义不同：放松模式 L50/L60 的 `phase2 = 0`，挑战模式是 `0.38 / 0.4`

| 关 | `levels.json`（挑战） | `levels_relax.json`（放松） |
|---|---|---|
| 50 | phase2 **0.38**，mug + mecha_doll | phase2 **0**，book + rocket |
| 60 | phase2 **0.4**，slipper + cactus | phase2 **0**，toilet + book |

- 判断：**不是冲突，是两套独立关卡表**（`modes.json` 里 challenge→levels.json、relax→levels_relax.json；放松模式的 `timeLimitMs` 为 null）。放松表 60 关 `phase2` 全 0，是因为它本来就不做错拍。
- 为什么要单列：测试同学按「第 50 关」去 relax 模式验证错拍，会看到「按一次就判定」——那不是 bug。**本表只描述挑战模式**，放松模式不适用。

### D4｜规则与数据的口径冲突：`inertia_hz` 全 60 关非 0（已按 P2 处理）

| 范围 | `inertia_px` | `inertia_hz` |
|---|---|---|
| L1–30 | **0** | 1.0（S1）、0.7/0.9/1.1（S2） |
| L31–60 | 2 → 6 px | 0.7/0.9/1.1 |

- 若照规则 4 字面（「`inertia_px`/`inertia_hz` 非 0 → 惯性」），**60/60 关全部标惯性**，该标签等于没有。
- **以 `inertia_px>0` 为判据**：hz 只是频率参数，px=0 时它不产生任何位移。改判后惯性 = 6 关（31/34/37/43/46/52），即 note 里点名「惯性」的那几关，与设计意图一致。
- 这不是 CSV/JSON 不一致（两侧取值一致），是**规则文字与数据默认值的冲突**，已在 §0.2-P2 留痕。

## 6. 复核方法与复现（谁都能重跑，2 秒出结果）

```python
import csv, json
rows = list(csv.DictReader(open('01_策划文档/levels.csv', encoding='utf-8-sig')))
J = {x['id']: x for x in json.load(open('assets/resources/config/levels.json', encoding='utf-8'))['levels']}

def label(r):                        # §0.1 + §0.2 全部口径
    d, dual = J[int(r['id'])], r['variant'] == 'dual'
    ph2, sine = float(r['phase_2']), float(r['sine_amp'])
    ipx, ihz, c2, note = float(r['inertia_px']), float(r['inertia_hz']), int(r['cycle_2_ms']), r['note']
    if dual and ph2 > 0: return '错拍·双物体'
    if '全机制' in note: return '机制·综合'          # P3-②
    if dual and sine > 0 and ipx > 0: return '机制·综合'   # P3-①
    if dual: return '双轮廓'
    if sine > 0 and '正弦' in note: return '正弦摆动'
    if '变速' in note or c2 > 0: return '变速'
    if '提速' in note: return '提速'
    if ipx > 0 and ihz > 0: return '惯性'            # P2：用 px
    return '基础·旋转'

tags = {int(r['id']): label(r) for r in rows}
cls = ['基础·旋转','提速','双轮廓','正弦摆动','变速','惯性','错拍·双物体','机制·综合']
for c in cls:
    ids = [i for i in sorted(tags) if tags[i] == c]
    gaps = [b-a for a, b in zip(ids, ids[1:])]
    print(c, len(ids), 'first=L%d' % ids[0], 'minGap=', min(gaps) if gaps else '-', ids)
```

预期输出与本表 §2 **逐字一致**（8 类、60 关、首现关号、最近间隔）。若不一致，先看 §0.2 的 P1–P4 是否被改动。
