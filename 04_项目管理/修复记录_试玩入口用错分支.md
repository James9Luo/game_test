# 20261022 · D-130 · 试玩入口用错分支（人类试玩玩的是"冻结静图"）

> 结论先行：**你之前在试玩入口里玩的不是游戏，是一张冻结的静态帧。**
> 那一刻时钟被钉住，物体不动；点一下就按"当前冻结相位"判一次 → 所以「按一次就判定了，没有第二次机会」。

## 一、证据链

| 环节 | 事实 | 证据 |
| --- | --- | --- |
| `?screen=play&lvl=N` 是什么 | **截图冻结分支**：把 `timeFreeze` 钉在某一帧 | `nowMs() { return timeFreeze === null ? performance.now() : timeFreeze; }`；实测 450ms 内 `now()` 不变 |
| 试玩入口用的是哪个 | `原型/试玩入口_v11.html` 的 iframe 与 10 个按钮**全部**是 `?screen=play&lvl=N` | 该文件第 40/54 行（已修） |
| 真可玩入口是哪个 | **`?start=N`**：正常跑时钟 | `startRun(app.mode, startN-1)`；实测倒计时 13.6s→12.9s、物体姿态变化（`motion_a.png` / `motion_b.png`） |
| 谁发现的 | 自动试玩 agent（用真实鼠标点击跑 60 关时发现的 P1） | `04_项目管理/自动试玩报告.md` §3 |

## 二、这意味着什么（对之前的反馈重新解读）

| 你之前的反馈 | 真实情况 |
| --- | --- |
| L50「按一次就判定了，没有第二次机会」 | 冻结帧下按一次就用冻结相位结算；错拍关的第二次定格在静图里根本走不到 |
| 「小了点 / 跟图鉴不一致」 | 静图里物体停在随机相位（且**没有运动**），和动起来看的手感完全不同；尺寸判断仍有效，节奏判断无效 |
| L8/L9「太赶 / 等太久」 | 冻结帧没有时间流逝 → 这类反馈**不能作为节奏结论**，需要真机可玩版重测 |

**注意：道具尺寸、双车道缩放、锤子换形、吉他配色这些改动都是基于静图也成立的判断（尺寸/形状），不受影响。**
