# 02_美术源文件 · 源工程区（绝不进 assets）

**一句话**：这里是「能改的东西」（PSD / AI / AE / 图集工程 / 未导出原画），引擎读不到也不该读到。

## 1. 四个子目录

| 目录 | 放什么 | 交付到 |
| --- | --- | --- |
| `ui_source/` | UI 界面 PSD/AI、按钮九宫格源、图标分层 | `03_交付素材/ui/` |
| `sprite_source/` | 物体、绿色轮廓、道具的分层原画 | `03_交付素材/sprite/` |
| `anim_source/` | AE/Spine 工程、序列帧源、动效曲线 | `03_交付素材/anim/` |
| `audio_source/` | 音效工程（Audition/Reaper）、BGM 分层 | `03_交付素材/audio/` |

## 2. 硬规矩

1. 源文件只在本目录迭代；**导出的成品才去 `03_交付素材/`**。
2. 每次导出必须同时交一张 `03_交付素材/交接单.md` 的条目（元素 / 尺寸 / 目标路径 / 是否覆盖旧版）。
3. 不提交引擎缓存、PS 暂存盘文件、`.psb` 中间稿的多个历史副本；历史靠 git，不靠 `_final_v3_真的最终.psd`。
4. 仓库超过 1GB 前必须决定是否上 Git LFS（见 `04_项目管理/决策记录.md` 待定项）。

## 3. 命名

`<类型>_<对象>_<序号>.psd`：`obj_cup_01.psd`、`outline_cup_01.psd`、`ui_btn_pause.psd`、`sfx_snap_01.wav`。
序号两位；同一元素的状态用后缀 `_n`（常态）/`_p`（按下）/`_d`（禁用）。
