# 03_交付素材 · 成品交接区（核对无误后才进 assets）

**它存在的唯一理由**：给「美术导出」和「程序导入」之间留一道验收闸门。这里的东西还**没有** `.meta`，改回源文件不用改工程。

## 1. 目录与去向

| 交付区 | 成品 | 导进 assets |
| --- | --- | --- |
| `ui/` | UI png / 九宫格 | `assets/art/ui/` |
| `sprite/` | 物体、轮廓 png（带透明通道） | `assets/art/sprites/` |
| `anim/` | 序列帧、Spine/AE 导出 | `assets/art/fx/`、`assets/anim/`（暂无则建） |
| `audio/` | wav / mp3 | `assets/audio/` |

## 2. 交付规格（策划定，美术执行，程序验收）

| 项 | 规格 | 为什么 |
| --- | --- | --- |
| 图片格式 | png-24 带 alpha；无色彩配置文件 | 小游戏包体与兼容 |
| 单图尺寸 | ≤ 1024×1024，超出切分 | 低端机纹理上限 |
| 尺寸基准 | 720×1280 竖屏，按 2 倍图交付（视觉 360 宽） | 与设计分辨率对齐 |
| 图集 | 同屏同时出现且 ≤ 512×512 的图进同一图集，≤ 8 张/图集 | drawcall |
| 命名 | 与 assets 目标路径文件同名：`obj_cup_01.png` | 导入零改名 |
| 音频 | 音效 wav 44.1k 单声道；BGM mp3 128k | 包体 |
| 锚点/九宫格 | UI 图必须说明锚点与九宫格边距 | 程序切图不猜 |

## 3. 交接单条目（每次交付必须写，追加到本文件末尾）

```
【交付｜美术 → 程序】日期 / 版本
元素：
文件：03_交付素材/sprite/obj_cup_01.png（512×512，alpha）
目标：assets/art/sprites/obj_cup_01.png（新增 / 覆盖 v1）
规格：锚点中心；九宫格 24/24/24/24（仅 UI 图填）
验收：策划确认尺寸与轮廓清晰度；程序确认导入后无紫块/边缘黑边
备注：
```
