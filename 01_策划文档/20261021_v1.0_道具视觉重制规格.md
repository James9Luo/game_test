## 2. 诊断：为什么旧 36 件「不像、也不美」（可量化）

| 指标 | 旧 36 件 | 新 14 件 | 说明 |
| --- | --- | --- | --- |
| 每件装饰条数（details） | **2.8**（0–4） | **15.9**（11–23） | 旧件几乎没有内部信息 |
| 填充色数 | **1**（fill 平涂） | 4–6（base/shade/light/deep + 强调） | 没有体积，只有剪影 |
| 结构线 | 平均 1.2 条 | 3–8 条 | 旧件靠 2px 描边"抠图" |
| 渐变/高光/内阴影 | 0 | 0（**刻意不用**） | 改为预烘焙不透明色块，引擎零风险 |
| 顶点数 | 14–31 | 12–44 | 曲线采样后抽稀，形状更准 |

一句话：**旧件像"贴纸"，因为一件物体只有一个色值；新件像"物件"，因为同色系被拆成 3–4 档并有结构线。**

## 3. 风格翻译：参考图 → 5 条可执行参数

参考图（热气球 / 小鸟）给出的语言：**平涂、无渐变、同色系分块、结构线勾语义、深色细描边**。落成参数：

## 4. 数据形态（零契约改动）

### 4.1 与 `shapes.json` 同构

```jsonc
{ "id": "cup_tumbler_v10", "name": "保温杯", "fill": "#9BBBD9", "stroke": "#4A6787",
  "size": 250, "pts": [{"x":…,"y":…}],             // 12–44 顶点，长边=1，形心=0
  "details": [
    {"k":"poly","pts":[…],"color":"#AFCCE4"},       // 色块（体积/语义）
    {"k":"line","pts":[…],"w":3.2,"color":"#5F7A96"} // 结构线（w = 设计 px）
  ],
  "srcId": "cup_tumbler", "band": "舒适", "kind": "器物", "note": "…" }
```

- **不引入 alpha**：明暗全部预烘焙成不透明多边形（提案 §3.3 的定调），绕开引擎 `Graphics` alpha 未验证的风险（R3）。
- 额外字段 `srcId/band/kind/note` 只给管线读，加载器不认也不报错（`shapes_check.mjs --file=` 已实测通过）。
- 可整份并入：`python 03_交付素材/check_shapes.py --merge 02_美术源文件/shapes_src/v10_backup_shapes.json --add`（**本轮不执行**）。

### 4.2 三道自动闸（构建时就挡住"穿模"和"过亮"）

| 闸 | 规则 | 不通过时 |
| --- | --- | --- |
| 内缩闸 | 所有 `details` 顶点必须在轮廓内（容差 0.7 单位） | 越界点**自动吸附到最近边界**（本轮共吸附 2 点：slipper/duck/burger 各 1） |
| 裁线闸 | 开口折线越界 | 按轮廓裁剪成多段，绝不画出去 |
| 亮度闸 | `L = (0.2126R+0.7152G+0.0722B)/255 ≤ 78%` | 自动往暗里拉直到达标 |

## 6. k 口径与实测（本轮新增工具）

### 6.1 之前没有工具能测"还没进关卡的形状"

`check_shapes.py` 只能自算再乘校准系数（K_SCALE），误差靠中位数压；旧形状的 k 是主策划 tool 跑出来的，新形状无路可走。

### 6.2 本轮补的 `tools/k_probe.mjs`（三层验证）

| 层 | 做法 | 结果 |
| --- | --- | --- |
| ① 真核 | 用 `core.buildLevel` + `core.hitWindow`（与游戏同一份判定代码）合成「单物体 / h_line / 2 圈 / 2600ms / passRate 0.6」 | —— |
| ② 口径自检 | `tools/k_verify.mjs` 复算真实前 5 关的 hitWindow，与 `levels.json` 派生值对比 | **差 0.0%**（逐位一致） |
| ③ 系数校准 | 用它跑旧 36 件，与 `check_shapes.py` 的 REF_LEAD_K 比 | 中位比值 **0.486**（0.425–0.499），与既有 K_SCALE 一致 |

> 结论：新集 k = 探针值 × 0.486，与旧表同一口径、同一把尺。脚本 `--file=` 可对任意形状文件复跑。

### 6.3 唯一越界件的处理

`burger_v10` k = 0.0584（上限 0.047，超 24%）。**接受，理由**：①咬痕已从 x=36 加深到 x=27，再削就不像汉堡；②本件只进图鉴/助眠池，不进 60 关——与 D-022 接受旧 burger 0.0499 同一条口径；③已在接触表上标注「接受（越界已记录）」，不隐藏。
