# v0.2 规格 · 双模式差异化 + 三场景 + 物体分层

> 2026-10-18 · 主策划 · 输入：用户《核心玩法体系（双模式差异化）》需求文档
> 本文是这份需求的**可执行版本**。判定口径、绿框静止、单键操作三条铁律**不动**；有冲突的地方在第 5 节逐条裁决。

## 0. 先说三处冲突（不解决就不能开工）

| 用户原文 | 与铁律冲突点 | 我的裁决 |
| --- | --- | --- |
| 判定框「缓慢呼吸动态」 | 绿框必须**固定不动**，否则判定与所见不一致 | **只允许发光呼吸**（外发光 α 0.35↔0.55，周期 4s），**轮廓几何点一个都不许动**。视觉上"在呼吸"，几何上"钉死" |
| 「小幅度惯性抖动」 | 随机只允许做速度微扰 | 抖动用**确定性正弦**（位移 ±6px，0.7–1.3Hz，相位由关卡固定），可练可背；随机仍只作用于速度 |
| 「潮流奥特曼」 | IP 风险（提审必挂） | 换成原创 **`mecha_doll`（小机甲玩偶）**：圆头、双肩甲、无任何可识别 IP 特征。测试运营在提审清单里加一条"无第三方 IP 形象" |

## 1. 双模式（同一套判定，两套节奏）

| 维度 | 催眠放松 `relax` | 闯关挑战 `challenge` |
| --- | --- | --- |
| 目的 | 无压力、助眠、可挂机 | 手眼考验、刷分、连击 |
| 关卡 | **无限流**：按物体池顺序循环，每次从 tier1/2 抽（权重 1:1） | 15 关固定梯度（沿用现有 `levels.csv`） |
| 周期 | **5200–6800ms**（比挑战慢 2–3 倍） | 1636–4153ms（现状） |
| 圈数 | 1 圈 | 1–3 圈 |
| 微扰 | `jitter = 0`（完全可预期） | 0–12% |
| 变速 | 无 | 已有固定两档（L5、L14） |
| 判定 | **照算重合率**，但**不判失败** | 完整评级 |
| 失败表现 | 无失败面板、无错误音、不扣次数：物体柔和淡出（α→0，300ms）后重新起飞 | 失败面板 + 安慰文案 + 扣 1 次 |
| 次数 | 无限 | 3 次/关 |
| 分数/连击 | **不显示**（内部仍记录 `pct` 与 `delta_ms` 供埋点） | 显示分数、连击、星级 |
| 音效 | 只有 `sfx_press`（-6dB）+ BGM（**-3dB 更轻**）；**不放评级音**（避免"叮叮"打断入睡） | 五档特效音齐上 |
| HUD | 只留：静音、场景、退出；**无分数、无连击、无次数点** | 关卡/次数/连击/分数 |
| 自动推关 | 不推关，永远停在同一关循环；玩家点"换一个"才换物体 | 通关自动下一关 |

**为什么 relax 还要判定**：不判就没因果了。**"卡准了有一声轻响 + 一圈柔光"** 就是全部奖励，没有分数压迫感。

## 2. 三场景（自动 + 手动）

| id | 名称 | 底色（上→下） | 动态元素（≤3 个） | 周期 | 亮度上限 |
| --- | --- | --- | --- | --- | --- |
| `night_station` | 深夜候车夜景 | `#0B1424 → #111E33` | 极慢柔云（2 层，α0.10/0.06）、远处车灯平移（1 条，α0.12，周期 22s）、星点（12 个，α0.05） | ≥18s | 元素叠加后 < 背景 +18% |
| `noon_window` | 午休窗边 | `#F6F1E7 → #E8EEF4` | 窗格光斑（3 个椭圆，α0.14，缓慢漂移 26s）、窗帘微动（1 条正弦，振幅 1.2%，周期 14s） | ≥14s | 同上 |
| `minimal` | 极简纯净 | `#141A24 → #0E1420` | 细碎粒子（16 个，α0.06，超慢上浮 30s） | ≥30s | 同上 |

**自适应规则**：
- 本地时间 **07:00–18:59 → `noon_window`**；**19:00–06:59 → `night_station`**；`minimal` 只能手动选。
- 手动选择优先级最高，存 `localStorage.dista.scene`；提供"恢复自动"（长按/再次点选自动项）。
- 切换发生在**关卡之间**，不在一局中途切（避免判定帧背景突变）。
- 三个场景**共用同一套判分与物体轮廓**：场景只换背景与氛围层，**不许改绿框位置、不许改物体颜色**。

**relax 模式的默认场景**：夜间自动 → `night_station`；白天 → `noon_window`。

## 3. 物体池（分层，与关卡梯度绑定）

| 层 | 造型原则 | 场景 / 关卡 | 物体 |
| --- | --- | --- | --- |
| **tier1 基础** | 规则、对称、匀速 | relax + challenge L1–L4 | `cup_tumbler` `car_hatch` `can_cola` `slipper` + **新增 `book`（书本）、`mug`（马克杯）** |
| **tier2 进阶** | 轻度不规则、轻微变速 | L5–L10 | `guitar` `wrench` `rocket` `tv` + **新增 `skateboard`（滑板）、`camera`（复古相机）、`handheld`（掌机）、`dessert`（甜品）** |
| **tier3 网红** | 曲面、角度刁钻、强传播性 | L11–L15 | `octopus` `cat` `duck` `burger` `toilet` `banana` + **新增 `crab`（卡通螃蟹）、`mecha_doll`（小机甲玩偶）** |

**新增 8 个形状的硬门槛**（与现有 15 个同一套）：
- 简单多边形、12–48 顶点、长边=1±2%、形心<0.05；
- **灵敏度 k ∈ [0.020, 0.047]**（2 圈/2600ms/60% 实测口径）；
- tier1 的 `book`/`mug` 要求 k ≥ 0.035（宽容），tier3 的 `crab`/`mecha_doll` 要求 k ≤ 0.030（严苛）。

## 4. 视觉与氛围（与风格圣经 §6 对齐，不另立标准）

| 项 | 规格 |
| --- | --- |
| 判定框 | 青绿 `#2BFFB0`，6px 描边 + 三层外发光；**发光呼吸** α0.35↔0.55 / 4s；内填充 8% 不变 |
| 定格瞬间 | 画面凝固（当帧冻结）+ 柔和高光呼吸（α0→0.22→0）+ 轻屏柔光；**无震动、无闪屏** |
| 判定热力 | 重合 `#2BFFB0` α0.35 / 偏差 `#FF5A5A` α0.60+外扩 2px / 空缺 `#E8F1FF` α0.25 |
| 全局质感 | 低饱和（饱和度上限 70%）、低对比、柔光影、磨砂通透 |
| 禁忌 | 高饱和尖锐特效 / 快节奏动态（任何循环 <8s 的装饰）/ 暗黑压抑 / 屏幕震动 / 红黑闪烁 |

## 7. 体积与工期

- **原型体积上限从 200KB 放宽到 400KB**（D-038）：200KB 是我给"可玩原型"定的自设目标，不是平台限制；生产包里场景与物体是独立资源，不进主包。当前 193.5KB，v0.2 预计 300–360KB。
- 工期：程序侧 1 轮（模式+场景+自适应+截图），美术侧 1 轮（scenes.json + 8 个新形状 + 3 张场景预览）。
