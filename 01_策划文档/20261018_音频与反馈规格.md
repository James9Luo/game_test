# 音频与反馈规格 · 《定格瞬间》 v0.3.0（三套 BGM 版）

> 2026-10-18 · 主策划 · 目标：**放松（relax）**。判定与数值一行不改，只改"听到"和"看到"。
> 铁律：BGM 与所有特效音**同调式、同音色族、同一混响**，任何一条不满足就算不协调。
>
> **v0.3.0 变更**：新增 §1b 三套 BGM（75/78/80 BPM，按 BGM 提示词文档实现）；
> 修正加法合成音色的长音包络（`env.hold`）；`renderBgm` 支持真无缝循环；
> 原 64BPM 曲目降级为对照样本。

## 0. 为什么"协调"可以写成数字

三条硬约束，程序照做就不会跑味：

| 约束 | 规定 | 违反的后果 |
| --- | --- | --- |
| **同调式** | 全部音乐只用 **D 大调五声音阶**：`D E F# A B`（D4=293.66Hz 起算） | 出现 C#/G，会立刻"现代/紧张"，不再放松 |
| **同音色族** | 只允许 4 个**加法合成音色预设**（见 §0b）+ `bandpass 噪声`（风声/沙锤）。**禁止裸三角波** | 方波/锯齿 = 电子刺耳；裸三角波 = 金属味 |
| **同混响** | 所有发声统一过一个反馈延迟：`delay 0.28s`、`feedback 0.30`、`wet 0.25` | 干湿不一 = BGM 像两个游戏 |

节拍：**64 BPM**（一拍 937.5ms）。8 小节一循环 = **30.0 秒**。

## 0b. 音色预设（v0.2.0 新增 · 替代裸三角波）

**为什么换**：v0.1 用「三角波 + 一极点低通」。三角波的谐波按 1/k² 衰减但**永不消失**，
而一极点低通在 2.6kHz 处只让谐波掉 1.8dB —— 结果是 D6（1175Hz）的 3.5k / 5.8k / 8.2k 谐波一直都在，
听感是金属亮片、发刺。这就是"跟真乐器差别大"的根。

**改成什么**：每个音色 = 一张**显式谐波表**。表里没有的谐波，物理上就不存在。

| 预设 | 用于 | 谐波（次数 / 振幅 / 独立 T60） | 听感目标 |
| --- | --- | --- | --- |
| `pluck` 拨弦 | BGM 拨弦、god | 1/1.00/1.3s、2/0.42/0.8s、3/0.22/0.42s、4/0.10/0.24s、5/0.045/0.14s、6/0.020/0.09s | 毡槌敲击：瞬时亮，50ms 后只剩基频 |
| `pad` 铺底 | BGM pad | 1/1.00/2.4s、2/0.26/1.7s、3/0.075/0.95s（双路 ±6 音分） | 温暖、不抢、无高频毛边 |
| `mallet` 音块 | perfect / good / ok | 1/1.00/0.95s、4/0.16/0.28s、6/0.055/0.14s | 钢片琴：2、3 次谐波**刻意不在**，纯音略带金属 |
| `sub` 低频垫 | BGM 低音、fail | 1/1.00/1.8s、2/0.10/0.9s | 撑住和声根音，不含任何刺耳谐波 |

**三条实现约束**（`tools/audio_check.mjs` 的 A11a / A11b 自动断言）：

1. 谐波必须**单调衰减**（第 n+1 次的振幅不得大于第 n 次），否则听感立刻变电子；
2. 16kHz 以上的谐波直接丢弃（只添"灰"，不添"暖"）；
3. 每根谐波起振相位**不齐**（真乐器每根弦的起振相位随机），否则波峰整齐叠加 → 音头硬。

## 0c. 包络语义（v0.2.0 修正）

`env.d` 的含义**改为 T60**：从峰值衰减 60dB 所需的秒数。

> **v0.1 的 bug**：`env.d` 实际被当成时间常数 τ 用（`exp(-t/d)`）。`d: 0.5` 意味着
> 400ms 后还有 `exp(-0.8)=45%` 能量。perfect 的三颗音间隔仅 90ms，叠加后总响度从 1.0 爬到 2.5，
> **比音头还响 4.3dB** —— 这才是"完美档刺耳"的第一主因（音量，不是音色）。

| 元素 | T60 | 等价听感 |
| --- | --- | --- |
| SFX god / perfect | 0.55s | 敲下去 200ms 内就散干净 |
| SFX good | 0.50s | 同上，更短 |
| SFX ok | 0.55s | 单音，平滑收尾 |
| SFX fail | 1.00s | 低频垫，慢慢沉下去 |
| BGM pad | 3.20s | 一小节内自然呼吸 |
| BGM 拨弦 | 2.60s | 留尾但不拖到下一拍 |
| BGM 低音 | 6.50s | 整小节支撑 |

## 0d. 电平层级（v0.2.0 修正）

v0.1 的组归一化把「最响的一档」顶到 −1.5dBFS，perfect 因此拿到 −8.0dBFS，
和 god 只差 6.5dB —— 奖励层级糊在一起，玩家听不出"这关打得特别好"。

v0.2 把组顶降到 **−2.0dBFS**，perfect 落到 −9.4dBFS（比 god 低 7.4dB），层级拉开。

| 档位 | v0.1 峰值 | v0.2 峰值 | ≥3.5kHz 尖峰变化 |
| --- | --- | --- | --- |
| god | −1.5 | −2.0 | −3.3 dB |
| perfect | −8.0 | −9.4 | −1.9 dB |
| good | −8.6 | −9.1 | −0.6 dB |
| ok | −17.1 | −18.9 | −5.7 dB |
| fail | −13.0 | −12.2 | +0.1 dB |

## 1. BGM（背景音乐）

| 元素 | 参数 |
| --- | --- |
| 和弦进行（每小节一个） | `Dmaj7` → `A` → `Bm7` → `Gmaj7`，两遍共 8 小节 |
| 铺底 pad | `sine` + `triangle` 各一，失谐 ±4 音分；attack 400ms / release 800ms；低通 1200Hz |
| 拨弦（毡音钢琴感） | `triangle`+`sine`；attack 5ms / decay 700ms；低通 2000Hz；每小节第 1、3 拍弹和弦根音+五度，第 2、4 拍后半拍加一颗高八度装饰音 |
| 低音 | `sine`，根音低两个八度，attack 300ms，音量比 pad 低 6dB |
| 沙锤 | 带通噪声（4–6kHz），40ms，每拍后半拍，**-26dB**（只要能听见"沙"） |
| 音量 | BGM 总电平 **-20dB**（相对主输出），保证不抢判定音 |

**不许做**：鼓组/底鼓、任何 8 分音符以上的密集节奏、突然的强弱对比、循环点留静音。

> **v0.3.0 起，本节的 64BPM 曲目降级为「对照原曲」（track id = `warm`）**，
> 正式在游戏内使用的是下面 §1b 的三套。原曲保留的原因：①它仍可用于旧存档/AB 对比；
> ②它的低音每小节硬起振，低频冲击 22.6dB（接近真鼓点），循环接缝跌落 21.2dB ——
> 正好作为"不该这么做"的负面样本。
>
> **2026-10-18 补记**：v0.3.0–v0.6 期间，代码的 `bgmDefault` 一直是 `warm`、`game.js` 也一直无参调用，
> 所以"正式使用三套"这句话到 v0.7 才真的成立（D-074 修调度、D-075 定映射）。

## 1b. 三套 BGM（v0.3.0 新增 · 按 BGM 提示词文档实现）

三套都满足的**硬约束**（每条都有自动断言，见 `tools/audio_check.mjs` A12a–A12h）：

| 约束 | 数值 | 依据 |
| --- | --- | --- |
| 速度 | **75–80 BPM** | 需求文档 §1「不要更快，太快增加紧张感」 |
| 曲式 | 8 小节无缝 loop | §4「4~8 小节」 |
| 动态 | 500ms 窗口 RMS 起伏 **≤ 7dB** | §3「全程平缓，不能有突强突弱」 |
| 循环接缝 | 首尾相接处 50ms 帧跳变 **≤ 4dB** | §4「循环点无断点、无突兀停顿」 |
| 无强鼓点 | 低频(≤150Hz)冲击峰/中值 **≤ 12dB** | §5「不要强鼓点」。校准：人工 kick 轨 26.2dB，原曲 22.6dB |
| 调式 | D 大调五声音阶 `{D,E,F#,A,B}` | §0 同调式 |
| 游戏内电平 | 比 `sfx_perfect` 的 RMS **低 15dB** | §2「BGM 比 SFX 低 -12~-18dB」，取中值 |

**动态窗口为什么用 500ms 而不是 50ms**：50ms 窗口测到的是每个音符自身的起落（实测 8.6dB），
那是音乐的呼吸，不是"突强突弱"。同一首曲子换窗口的结果：50ms 8.6dB → 200ms 6.3dB → 500ms 5.4dB。
500ms 更接近人耳判断"这段音乐整体多响"的尺度，故取它。

### 场景 → 曲目（D-075，v0.7 起）

| 场景 | 曲目 | 依据 |
| --- | --- | --- |
| `night_station`（深夜候车） | `lofi` | `lofi` 的定位原文就是"候车（推荐）"，场景名就是候车 |
| `noon_window`（午休窗边） | `minimal` | 最干净、无噪声层，白天不抢注意力 |
| `minimal`（极简） | `ambient` | 弦乐垫 = "最远"，配极简的静态感 |

- **冷启动兜底 = `minimal`**：`SPEC.bgmDefault = 'minimal'`（D-075，v0.7 起），`game.js` 冷启动顺序改为"先 `resolveSceneId()`，再 `startBgm(映射后的曲)"。两处都改，是因为**只改调用方 = 把坑留在地板上**：任何一次无参 `startBgm()` 都会退回 `warm`。
- **切曲在下一次循环边界生效**：`setBgmTrack` 只写 pending，由 `scheduleBgmLoop` 消费；不是 stop+start 硬切。
- **为什么默认不是 `lofi`**：三轨里只有它带打击乐（每拍刷镲，0.8s 一个脉冲）。在"卡时机"的玩法里，可数的拍点会和物体周期争抢锚点。判据与盲听问卷见 `20261018_v0.7_道具BGM视觉三线规格.md` §3.2。

### 三个关键实现点（都踩过坑，写下来免得重犯）

1. **长音必须能表达"衰减很慢"**。`writeHarmEvent` 原本让总包络在起音后恒为 1.0，
   衰减只由每根谐波的 `h.dec` 决定 —— 事件上写的 `env.d` 对加法合成**完全无效**。
   结果铺底音在满音量下被 60ms 软收尾掐断，每小节末掉到 −58dB，小节之间"断了气"（动态 47.6dB）。
   现在：`env.hold === true` 时启用事件级 T60，与谐波级 T60 **取慢者**。
   不默认启用，是为了不改动 v0.2 原曲（它的 pad 写 `d:3.20`，若被当长音处理，原曲 RMS 会从 −18.80 跑到 −18.11）。

2. **循环接缝要靠"电平自洽"，不是靠淡入淡出**。两个机制：
   - 渲染时多算一段 bleed（3.0s），把这截尾巴**叠加回开头**再裁到精确 loop 长度（`renderBgm(..., seamless=true)`）；
   - 长音 T60 取"一整圈正好衰减 15dB"，于是每圈起点电平完全一致。
   15dB 是实测扫出来的：15dB → 动态 7.3~8.6 / 接缝 1.1~2.6；20dB → 6.7~10.3 / 1.6~2.9；
   30dB → 6.6~12.2 / 2.5~3.4。衰减越少，圈尾越接近圈头，接缝越连续。

3. **交付版与试听版必须分开**。压到 −39.2dBFS 的 BGM 单独播放会让人以为"没声音"，
   但文档要求的电平关系只在**和音效一起播**时才成立。所以每套出两个文件：
   `*_preview.wav`（−18dBFS，试听用）与 `*.wav`（−39.2dBFS，游戏内用）。

## 2. 特效音（按评级分级，全部在 D 大调五声音阶内）

| 事件 | 音高序列（Hz 见 §6） | 时值 | 音色 | 相对音量 | 听感目标 |
| --- | --- | --- | --- | --- | --- |
| `sfx_press` 按下/冻结 | 无音高（带通噪声 2kHz，60ms） | 60ms | 噪声 | -18dB | 像按下了暂停键的"嗒"，**随即所有风声骤停** |
| `sfx_god` 神级 | D5 → F#5 → A5 → D6（间隔 80ms） | 1.2s | triangle+sine 双失谐 | +6dB | 向上四音、亮但不炸；带一层空气感 |
| `sfx_perfect` 完美 | A4 → D5 → F#5（间隔 90ms） | 0.9s | 同上 | +2dB | 柔和上扬 |
| `sfx_good` 不错 | D5 → A5（间隔 110ms） | 0.6s | sine 为主 | 0dB | 两个音，收得干净 |
| `sfx_ok` 及格 | 单音 D5，尾部下滑 20 音分 | 0.5s | sine | -4dB | "嗯，还行"的短句 |
| `sfx_fail` 失败 | D3 + F#3（纯五度下方） | 0.9s | sine，attack 120ms | -6dB | 低沉但不刺，**不用下滑长音**（那会像"错误提示"） |
| `sfx_whoosh` 飞行风声 | 带通噪声 300→900Hz 随接近目标上扫 | 持续 | 噪声 | -22dB | 有"飞行"但不吵 |

**关键设计**：`sfx_press` 播放的同一帧，`sfx_whoosh` **硬切为 0**。**"静音"本身就是奖励**——风声停了，玩家才知道自己把时间按停了。这一条是这个游戏最重要的声音设计。

**闪避（ducking）**：任一级特效音触发时，BGM 增益 ×0.55，250ms 后线性恢复。

## 3. 动画与反馈（relax 版；替换原「闪白」方案）

原方案是全屏闪白 α0.55——那是"打击感"，与 relax 冲突。改为**柔光呼吸**：

| 时序（从按下那一帧起） | 效果 | 参数 |
| --- | --- | --- |
| 0ms | 冻结当帧；风声硬切 | — |
| 0–140ms | 柔光：以绿框为中心的径向光晕淡入 | α 0 → 0.22，色 `#2BFFB0` |
| 140–400ms | 光晕淡出 | α 0.22 → 0 |
| 120ms 起 | 热力图淡入（三色，见 3.2） | 重合 α0.35 / 偏差 α0.60 / 空缺 α0.30 |
| 260ms | 结算面板上滑 | 位移 70px，`easeOutCubic`，**无回弹** |

### 3.2 热力图的信息层级（relax 不等于全暗）

| 区域 | 颜色 | α | 形变 | 为什么 |
| --- | --- | --- | --- | --- |
| 重合（交集） | `#2BFFB0` | **0.35** | — | "对的"应该安静，不抢注意力 |
| 偏差（并集−交集） | `#FF5A5A` | **0.60** | **外扩 2px** | 玩家最需要知道"错在哪"；重合率 90%+ 时偏差只剩 1–3px，不外扩看不见 |
| 空缺（绿框没被盖住） | `#E8F1FF` | **0.25** | — | 去饱和中性灰 = "这儿什么都没有"；青绿会与重合区撞色（实测 ΔH 3.1°、ΔL 4.5 个百分点，紧邻两块读不出差别） |

恒定叠加**两套轮廓**：物体实线 + 绿框虚线（dash 6/6，α0.55）。这样任何重合率下都能指出偏移方向——靠形，不靠亮度。
偏差区 α 上限 0.65：再高会盖住物体本身的识别度。

### 3.1 按评级分级（这正是玩家要的"不同的动画"）

| 评级 | 缓动/时间 | 环（从绿框扩散） | 粒子 | 画面其余变化 |
| --- | --- | --- | --- | --- |
| **神级** | 0.35× 慢放 600ms，再 400ms 回 1× | **3 环**，间隔 180ms，色 mint→gold，α0.35，900ms | **24 颗**微尘，向上漂，1.2s，r=2，α0.5 | 背景色相偏 8°（更暖），HUD 数字微亮 |
| **完美** | 1× | **1 环**，600ms | 12 颗，0.9s | 绿框描边加粗 1px 后恢复 |
| **不错** | 1× | 无环 | 无 | 绿框呼吸一次（α 0.35→0.12，400ms） |
| **及格** | 1× | 极淡 1 环（α0.12） | 无 | 只有文案，无其它变化 |
| **失败** | 1× | 无 | 无 | 物体 α → 0.65（200ms）；**不抖屏、不红闪、不震动**；文案柔和 |

缓动一律 `easeOutCubic` / `easeInOutCubic`；**禁止**弹性回弹（bounce）、抖动（shake）、红黑交替闪烁。

粒子预算：单帧 ≤ 120 个（含微尘），神级 24 颗一次生成，2 秒后全部回收。

## 4. 静音与首次播放

- 浏览器自动播放策略：**必须由用户手势启动**（点「开始」时 `AudioContext.resume()`）。未手势前不创建上下文。
- 右上角一个 44×44 的静音开关（α0.4，点一下切 BGM+SFX），**它不算"第二个按钮"**——它不参与玩法。
- 记住静音状态（`localStorage`），但**默认为开**（用户要的就是音乐）。

## 5. 重开规则（本版新增的行为修正）

| 入口 | 行为 |
| --- | --- |
| 首页主按钮「开始」 | **永远从第 1 关开始**（重置本局分数/连击，不清空存档里的最好成绩） |
| 首页次按钮「继续 · 第 N 关」 | 仅当存档进度 > 1 时出现；点了从第 N 关继续 |
| 结算页「重试本关」 | 同一个关卡号重来，不改变进度 |
| 通关页「再玩一次」 | 回第 1 关 |
