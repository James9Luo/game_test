## 1. 为什么有这一版

v0.4 把 60 关做出来了，但「后 45 关的机制新鲜感」不足，实测下来是三个问题：

| # | 问题 | v0.4 实测 |
| --- | --- | --- |
| 1 | 路径单一化 | 季 2–4 **全部 `h_line`**（为了保证窗口阶梯可调而统一） |
| 2 | 机制参数季内是常量 | 正弦 0.10/0.12/0.14 每季一个值贯穿 15 关 |
| 3 | 机制首现太稀 | 只有 3 个（L10 双物体、L16 正弦、L31 惯性），平均 **20 关一个** |

v0.5 把这三条压到：**路径按季渐进（2/3/4 条）、机制节点固定每 3 关一个（共 15 个）、机制关不提速**。

## 3. 路径渐进放开

| 季 | 路径集合 | 分配方式 |
| --- | --- | --- |
| 季 1 | 7 条（v0.3 原样，冻结） | 不动 |
| 季 2 | `h_line` + `diag_dl` | **按关序渐进**（越靠季末越弯） |
| 季 3 | + `arc_up`（3 条） | 同上 |
| 季 4 | + `bounce_floor`（4 条） | 同上 |

- **双物体关一律 `h_line`**：车道 1 是车道 0 的等距变换，弧线/弹跳会让顶点飞出可玩区（y≈1360）。要放开需先加"车道 1 垂直压缩"规则并重算窗口。
- **不要用 `i % 路径数` 循环分配**：实测会让难度跳动（阶梯出现 49→73 的回升）。按关序渐进时，路径难度与关卡进度同向。

## 4. 一条否定结论：相位与正弦频率不是"机制"，是调参旋钮

实测（真 core，三个关，`HitWindow` 直接测）：

| 关 | 正弦频率 r=0.35 / 0.50 / 0.65 | 相位 φ=0 / 0.25 / 0.5 / 0.75 |
| --- | --- | --- |
| L49（amp 0.14，3 圈） | 94 / 102 / 110 ms（±8%） | 102 / 92 / 98 / 109 ms（±9%） |
| L55（amp 0.14，3 圈） | 33 / 31 / 28 ms（±8%） | 32 / 28 / 31 / 35 ms（±11%） |
| L22（amp 0.12，2 圈） | 186 / 192 / 202 ms（±4%） | — |

**判据**：季内相邻关卡之间的窗口差是 **30%+**，而相位/频率只带来 ±10%——**玩家察觉不到，不能算机制节点**。

因此：
- `sine_phase=0.5` 从机制表**撤掉**（数据里 `sinePhase≠0` 的关 = 0）；
- L55/L58 改为 **`sine_period = 0.35 × cycle`（呼吸加快）**：速度起伏变密，**视觉可见**，但窗口变化 <10%，属于"难度中性"的机制节点——正好符合"机制换难度不加速"。

**反例留档**：我们一度按"φ=0.5 能镜像早/晚"写断言，45 关实测 **0 关互换**。根因是早/晚不对称主要来自形状在 ±旋转下的轮廓差异与惯性抖动方向，正弦相位在窗口 ±50ms 内只贡献约 ±5%。**断言只断言性质（唯一/无双峰/确定性），不断言我们对物理的猜测。**

## 5. 求解方法：四级流水（路径放开后必需）

| 阶段 | 做什么 | 为什么 |
| --- | --- | --- |
| A | 按季目标窗口挑形状（未用过者优先 4ms，允许重复） | 单靠周期无解（32 关偏差 >3ms） |
| B | 二分周期把窗口钉到目标（**机制节点跳过**） | 机制节点靠机制换难度，不靠提速 |
| C | 单调兜底：任关窗口大于前一关 → 同周期换更敏感形状 | 保证季内阶梯单调 |
| D | **机制节点周期拉回前一关**（不加速） | 阶段 B 会把其它关加速，导致后面的机制节点相对变快 |

工具：`_probe/gen60.mjs`（生成）→ `_probe/ladder.mjs`（A–D 求解）→ `tools/export_levels.mjs`。
