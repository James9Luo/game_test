## 1. 概念与一句话卖点

**一句话**：物体在空中翻滚飞过，绿色轮廓钉在屏幕中央不动——你在两者重合的那一瞬按【暂停】，卡得越准分越高。

| 项 | 值 |
| --- | --- |
| 品类 | 2D 反应 / 魔性解压 |
| 平台 | 竖屏 720×1280；微信/抖音小游戏优先，Web 兜底 |
| 目标用户 | 碎片时间玩家、爱拍屏分享的人 |
| 单局时长 | 8–20 秒（单次尝试 4–6 秒） |
| 学习成本 | 0 文字教学；3 秒内看懂 |
| 差异点 | 判定是**轮廓面积**不是中心点——「角度歪一点」就不给满分 |

**卖点排序**：① 一眼看懂 ② 「就差一点点」的抓狂 ③ 高光可复现、可分享。

## 2. 核心循环

```
进入关卡(1s) → 物体进场(0.6s) → 逼近绿框(1~2s) → 【按下】 → 冻结+判定(0.26s)
     ↑                                                        ↓
     └──── 重试(0.7s) ←── 失败/未达标 ←── 结算面板（评级+早了晚了+得分）
```

- 一个循环 = **一次尝试**，目标 4–6 秒。
- 一关 3 次机会；通关后 1 秒内自动进下一关，**不进菜单**（减少一次点击就多一次重玩）。
- 退出点在结算面板：`再来一次`（默认高亮）/ `下一关`（已通关）/ `回首页`。

**因果链检查（任何新玩法先过这一关）**：本作里「早按 / 晚按」→「重合率」→「评级」→「分数」全程可视、可复述。**加任何机制，都必须让这条链更清楚，而不是更模糊。**

## 3. 操作与判定

- **唯一操作**：点【暂停】（整个屏幕都是点击热区，视觉上按钮直径 212px，位于 (360,1122)）。
- **判定时机**：以「按下那一帧的精确时间戳」回滚到该时刻的物体姿态再算分，**不用下一帧状态**。
- **判定公式**（口径锁死，详见数值与判定表）：

```
重合率 pct = 交集面积 / max(物体面积, 目标面积) × 100
评级：神级 ≥95 | 完美 ≥80 | 不错 ≥60 | 及格 ≥40 | 失败 <40
```

- 同时输出三项给文案与热力图：`pct`、`角度偏差(带符号)`、`形心位移(px)`。
- **早/晚**：`deltaMs = 按下时刻 − 完美时刻`（环绕到 ±半个周期），`|delta| ≤ 16.7ms` 记「时机刚好」。
- 边界（测试必测）：0 分 / 100% / 连点 / 暂停中再点 / 物体已离场 / 首帧按下 / 同 seed 复现。

## 4. 玩法模式

| 模式 | 优先级 | v0.1 状态 | 规则要点 |
| --- | --- | --- | --- |
| 闯关 | P0 主线 | **做** | 15 关，每关 3 次机会，星级 1–3 |
| 无尽挑战 | P1 | 接口预留（CSV `weight`） | 随机出场，连击累加，速度随连击上升 |
| 变幻速 | P2 | 并入闯关第 5 关 | **固定两档变速**（切换点 u=0.4），不做随机加减速 |
| DIY 工坊 | P2 传播 | 接口预留 | 上传图 → 去背 → 提轮廓 → ≤64 顶点 → 关卡码 |

**砍掉的**：轮廓晃动变体（违反「绿框不动」铁律）。要复活必须单独立项并写决策记录。

## 5. 关卡与难度曲线

15 关完整配置见 `levels.csv`（14 个必填字段 + 6 个扩展字段）。曲线原则：**每次只推 1–2 个难度变量**。

| 变量 | 说明 | 用在哪 |
| --- | --- | --- |
| 速度 | 周期 `cycle_ms` 与圈数 `turns` | L1–L15 主推力 |
| 形状敏感度 | 长宽比 / 轮廓不规则度（容错角度的来源） | L3、L6、L8 换形 |
| 扰动 | 速度微扰 `jitter`（≤15%） | L6 起逐步加 |
| 组合 | 双轮廓、变速 | L5、L10、L15 |

分段曲线（目标值，实测定稿见数值表）：

| 段 | 关 | 新增变量 | 目标通关率（对应技能档） |
| --- | --- | --- | --- |
| 教学段 | L1–L2 | 速度 ↑ | L1 新手 60–85% |
| 换形段 | L3–L4 | 形状 ↑、圈数 ↑ | L3 新手 55–75% |
| 变速段 | L5 | 固定两档变速 | L5 普通 50–70% |
| 不规则段 | L6–L9 | 长宽比 ↑、抛物/弹跳 | L8 普通 45–65% |
| 双轮廓段 | L10 | 双物体同帧卡位 | L10 熟练 40–60% |
| 高速段 | L11–L14 | 速度 ↑↑、扰动 ↑ | L14 熟练 30–50% |
| 终局 | L15 | 双轮廓 + 高阈值 | L15 熟练 25–45%，神级 ≤3% |

## 6. 数值

详见 `20261018_数值与判定表.md`。本文件只锁三个数：

1. **评级阈值** 95 / 80 / 60 / 40（连续无缝，无空档）。
2. **基础分** 1000 / 600 / 350 / 150 / 0；`score = round(base × min(2, 1+0.1×连击) × 模式系数)`。
3. **容错不是旋钮**：新手关 ±15°、高难关 ±3° 是**结果指标**——由形状敏感度和速度共同决定，策划不直接改判定公式。

## 7. UI 与反馈（含音效需求）

| 时序 | 时长 | 画面 | 音效 |
| --- | --- | --- | --- |
| 按下 | 0ms | **当帧冻结**，按钮高亮，物体停下 | `sfx_snap_01`（"咚"） |
| +0~90ms | 90ms | 全屏闪白（α 0.55 → 0） | - |
| +90~210ms | 120ms | 热力图淡入：绿=重合 / 红=偏差 | 轻微"嘶"（可省） |
| +210~470ms | 260ms | 评级面板弹出 + 早/晚文案 | 评级音：神级"叮！"、完美"叮"、失败"嗷～"（不刺耳） |
| 常驻 | - | HUD：关卡名 / 剩余次数圆点 / 连击 / 总分 | 飞行风声（低音量） |

**文案铁律**：必须告诉玩家**按早了还是晚了、差多少毫秒、少转多少度**。只说"失败"等于不教。

## 9. 社交与传播

- **结算页 3 秒内可导出**：截图或 10 秒录屏；水印含玩法一句话（「看准时机，一键暂停」）。
- **失败也能分享**（自嘲传播 > 炫耀传播）：失败文案必须是「好笑」而不是「羞辱」。
- **分享卡片字段**：关卡 + 重合率 + 评级 + 一句话 + 二维码。
- 目标：分享率 ≥8%（验收见埋点表）。
