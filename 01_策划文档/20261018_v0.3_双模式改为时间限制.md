# v0.3 修订 · 双模式的真正差异 = 时间限制

> 2026-10-18 · 主策划 · 用户澄清：「挑战每关限时、15 关、最后统计最高分；催眠很类似第一版，无时间限制，合格就进下一关；**特效和评分系统两个玩法都跟第一版一样**」
> 本文覆盖 v0.2 规格里"relax 不判失败/不显示分数/不放评级音"那一整套设计——**那是我误读，作废**。

## 1. 唯一的差异：时间

| 维度 | 闯关挑战 | 催眠放松 |
| --- | --- | --- |
| **每关时限** | **15 秒**（超时＝本关失败） | **无时限** |
| 每关机会 | 3 次（超时或 3 次用完都算本关结束） | 3 次（用完只重开本关，无惩罚） |
| 关卡数 | **15 关打完 → 结算** | 15 关打完 → **回到第 1 关继续**（记录轮次） |
| 关卡推进 | 合格 → 下一关 | 合格 → 下一关（同前） |
| 失败 | 弹失败面板（同 v1） | 弹失败面板（同 v1）——**只是没有倒计时压力** |

## 2. 两个模式完全相同的部分（= 第一版）

- **判定**：`重合率 = 交集 / max(两者面积)`，扫描线精确积分。
- **评级**：神级 ≥95 / 完美 ≥80 / 不错 ≥60 / 及格 ≥40 / 失败 <40。
- **分数**：1000 / 600 / 350 / 150 / 0；`score = base × min(2, 1+0.1×连击)`。
- **星级**：一星 = 达到本关通关线；二星 = 通关线 + 0.7×(三星线−通关线)；三星 = 三星线。
- **动画**：柔光呼吸 + 五档分级（神级 3 环 + 24 微尘 / 完美 1 环 + 12 微尘 / 不错呼吸 / 及格极淡一环 / 失败物体降透明度）。
- **音效**：五档评级音 + 按下那一声 + 风声硬切 + ducking（全部与 v1 一致）。
- **HUD**：关卡号 / 剩余次数点 / 连击 / 得分 —— 两个模式**都显示**。
- **反馈时序**：闪白已废（D-028），柔光 140/260ms → 热力 120ms → 面板 260ms。

## 3. 时间限制的具体规则（挑战模式）

| 项 | 规则 |
| --- | --- |
| 时长 | 每关 **15 秒**（`modes.json: challenge.timeLimitMs = 15000`，可单关覆盖 `levels.csv` 新列 `time_limit_sec`） |
| 起点 | 本关**第一次物体进场**时开始（不是进关那一帧，避免读秒前先掉 1 秒） |
| 暂停 | 结算面板出现即停表；重试本关**重置为 15 秒** |
| HUD 位置 | 顶部右侧，与得分同列上方；显示 `12.4s`（一位小数）、≤3s 时数字切琥珀 `#FFC44D` 并轻微呼吸（**不用红色、不闪烁、不震动**） |
| 超时表现 | 立即进入结算：评级 `fail`、文案「时间到」；**扣掉本关最后一次机会**；次数还有就允许重试本关，次数用完 → 显示「本关结束，可重试」 |
| 不打表的情况 | 首页、结算面板、通关页、relax 模式 |

**为什么是 15 秒**：最慢的一关（L1 周期 3.78s）在 15 秒内能看 3.9 个周期、按 3 次；最快的一关（L10 1.64s）能看 9 个周期。低于 12 秒会让 L1 的玩家"刚看懂就到点"，高于 18 秒则失去紧迫感。**这是起点值，上线后按埋点 `attempt/judge` 的时间分布再调。**

## 4. 结算与最高分

| 场景 | 显示 |
| --- | --- |
| 挑战 15 关全部通关 | 通关页：**本局总分** + **历史最高分**（`localStorage.bestScore`，只增不减）+ 神级次数 + 用时；点「再玩一次」回第 1 关 |
| 挑战中途某关次数用尽 | 结算面板给「重试本关」/「回首页」；**总分不清零**，重试继续累计 |
| 催眠 15 关循环 | 每轮结束显示一次「第 N 轮完成 · 本轮 N 分」轻提示（2 秒自动消失，不打断），不计历史最高 |
| 最高分口径 | 只在挑战模式记录；催眠模式不参与排名（避免助眠玩家被分数绑架） |

## 5. 验收（新增，覆盖旧的 relax 断言）

| # | 项 | 判定 |
| --- | --- | --- |
| M13 | 挑战有倒计时 | `challenge` 下 `timeLeftMs` 随时间递减，`relax` 下恒为 `null` |
| M14 | 超时进结算 | 把时钟快进 15s 不按 → `scene=feedback`、`fb.timeout=true`、评级 `fail` |
| M15 | 超时扣次数 | 超时一次后 `attempts-1`；`attempts=0` 时给「本关结束」 |
| M16 | 重试重置计时 | `startLevel` 后 `timeLeftMs` 回到 15000 |
| M17 | 两模式评分一致 | 同一关同一 `pressMs`，两模式的 `pct/rating/score` 完全相同 |
| M18 | 两模式特级一致 | `relax` 也放评级音、也显示分数与连击、也弹面板 |
| M19 | 催眠推进 | `relax` 完美按下 → 合格 → 下一关；第 15 关后再进 = 第 1 关且轮次 +1 |
| M20 | 最高分 | 挑战通关后 `bestScore = max(旧, 本局)`；催眠不写 `bestScore` |

## 6. 作废的旧设计（别再按它实现）

| 旧（v0.2） | 现在 |
| --- | --- |
| relax 不判失败、不扣次数 | ❌ 作废。relax 与挑战一样判失败、一样弹面板 |
| relax 不显示分数/连击/次数 | ❌ 作废。两个模式 HUD 一样 |
| relax 不放评级音、BGM -3dB | ❌ 作废。音效与 v1 一致（BGM 增益两模式相同） |
| relax 每 3 次定格换物体 | ❌ 作废。改为"合格就进下一关" |
| challenge 无时限 | ❌ 作废。15 秒/关 |

**唯一保留的 relax 差异**：没有倒计时，且 15 关打完回第 1 关继续（挑战是结算）。
