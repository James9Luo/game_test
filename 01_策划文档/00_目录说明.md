## 1. 数据流（单向，禁止手改下游）

```
01_策划文档/levels.csv  ──导出──▶  assets/config/levels.json  ──只读──▶  程序
        │                                        │
        └────────── 同一份数值口径 ──────────────┴──▶ 测试用例 / 判定单测
```

规矩：程序不许在 ts 里写死阈值；策划改数只改 `levels.csv` + 重导出，并记一版 `版本日志`。

## 3. `levels.csv` 字段（缺一个都不算合格）

| 字段 | 单位 / 取值 | 说明 |
| --- | --- | --- |
| id | 整数，唯一 | 关卡编号 |
| name | 文本 | 给玩家看的名字 |
| object_id | 资源 id | 物体贴图 id，对应 `assets/art/sprites/` |
| outline_id | 资源 id | 绿色目标轮廓 id（可与物体不同，制造难度） |
| motion_type | 旋转 / 抛物 / 弹跳 / 组合 | 运动类型 |
| ang_speed_min / ang_speed_max | 度/秒 | 角速度区间，**给区间不给单值** |
| lin_speed_min / lin_speed_max | 像素/秒（720 宽基准） | 线速度区间 |
| jitter | 0–0.15 | 速度微扰上限百分比，只扰速度不改路径 |
| tolerance_deg | 度 | 允许角度偏差（参考：15 → 8 → 3） |
| pass_rate | 0–1 | 通关阈值（重合率） |
| star3_rate | 0–1 | 三星阈值 |
| est_seconds | 秒 | 单次尝试合理耗时 |
| weight | ≥0 | 无尽模式出场权重 |
| note | 一句话 | 设计意图 |

一关最多同时上升 **两个** 难度变量（速度 / 形状复杂度 / 容错角度 / 扰动强度），第三个变量必须回退。

## 4. 判定口径（写死在文档里，中途不许改）

1. 判定 = **轮廓重合面积**（IoU 或 交集/目标面积），不是中心点距离。
2. **绿色目标轮廓固定不动**，动的只有物体。
3. 随机只做速度微扰，不改基础路径。
4. 角度偏差与位移偏差**分开算再加权**，不合成一个模糊数。
5. 任何新玩法先回答：它有没有让「按早了 / 按晚了」的因果更清楚？答不上来就砍。
