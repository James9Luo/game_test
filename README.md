# dista · 2D 反应类小游戏（Cocos Creator 工程）

| 项 | 值 |
| --- | --- |
| 项目代号 | dista · 正式名**《定格瞬间》**（别名：暂停大师） |
| 引擎 | Cocos Creator 3.8.x（LTS，默认按 3.8.6 落配置） |
| 核心玩法 | 物体高速翻滚 / 抛飞，绿色目标轮廓固定不动；玩家在两者重合的瞬间点【暂停】，重合度越高分越高 |
| 判定口径 | **轮廓重合面积**（交集/并集 或 交集/目标面积），**不是中心点距离** |
| 单局时长 | 8–20 秒 |
| 本迭代出口 | 垂直切片：L1–L3 可玩 + 判定可复现 + 首屏 UI 线框 |

---

## 1. 三条铁律

1. **`assets/` 是引擎唯一资源根**：只放引擎要读的东西（png / wav / prefab / scene / ts / json）。PSD、AI、AE、源工程、未导出原画一律不许进。
2. **资源单向流动**，禁止逆向拷贝：
   `02_美术源文件` --导出--> `03_交付素材` --核对验收--> `assets/`
   逆向（assets → 03 / 02）只在「已上线素材回补源文件」时由美术执行，并记进 `04_项目管理/决策记录.md`。
3. **一个文件同一时间只允许一个岗位改**。目录级写作用域见第 5 节；并行作业靠目录隔开，不靠口头约定。

## 3. `assets/` 内部约定

| 子目录 | 放什么 | 命名样例 |
| --- | --- | --- |
| `scenes/` | 场景 | `GameMain.scene`、`Level_01.scene` |
| `scripts/core/` | 判定、状态机、计分（**纯逻辑，不引用 art/**） | `OverlapJudge.ts` |
| `scripts/gameplay/` | 物体运动、关卡加载、输入 | `Mover.ts`、`LevelLoader.ts` |
| `scripts/ui/` | HUD、结算、暂停 | `ResultPanel.ts` |
| `art/sprites/` | 物体与绿色轮廓 | `obj_cup_01.png`、`outline_cup_01.png` |
| `art/ui/` | UI 图 | `btn_pause_n.png` |
| `art/fx/` | 特效帧 / 粒子贴图 | `fx_hit_01.png` |
| `audio/` | 音效与 BGM | `sfx_snap_01.wav` |
| `prefabs/` | 预制体 | `obj_cup.prefab` |
| `config/` | **由策划表导出**的 JSON（程序只读，不手改） | `levels.json`、`judge_rule.json` |

硬规矩：

- **`.meta` 文件必须提交**，删了会导致场景/预制体引用丢失。
- 数值不许写死在 ts 里：判定阈值、速度区间、容错角度全部来自 `config/`。
- `scripts/core/` 不许 `import` 任何美术资源，保证判定逻辑可单测。

## 4. 首次打开（5 步）

1. 装 Cocos Creator 3.8.x（Dashboard 里的版本号要与 `package.json` 的 `creator.version` 一致；不一致时编辑器会提示升级项目，别点，改 package.json 的号）。
2. Dashboard → 项目 → 添加 → 选 `E:\game_design\dista` → 打开。
3. 首次导入会生成 `library/`、`temp/`、`settings/`、`local/`、`profiles/`；导入完成后检查 Console 无报错。
4. 项目设置里确认：设计分辨率 `720×1280`、适配方案 `Fit Width`（**待验证**：竖屏首屏与分享卡片比例，验证方法见 GDD 第 7 节）。
5. 提交一次空工程基线，`.gitignore` 之外的变更应只有 `assets/`、`settings/`、`package.json`、`tsconfig.json`。

## 5. 写作用域（并行作业必读）

| 岗位 | 可写 | 只读 |
| --- | --- | --- |
| 主策划 | `01_策划文档/`、`04_项目管理/` | 其余全部 |
| 客户端程序 | `assets/scripts/`、`assets/scenes/`、`assets/prefabs/`、`assets/config/` | `01_策划文档/`、`03_交付素材/` |
| 2D 美术 | `02_美术源文件/`、`03_交付素材/`、`assets/art/`、`assets/audio/` | `01_策划文档/` |
| 测试运营 | `04_项目管理/BUG清单`、`04_项目管理/版本日志` | 其余全部 |

冲突裁决：手感与数值 → 策划；实现与工期 → 程序；视觉一致性 → 美术；上线风险与合规 → 测试运营。拍板结果写入 `04_项目管理/决策记录.md`。

## 6. 命名规范

- 目录用中文（人看的），`assets/` 内文件名用英文小写下划线（引擎看的）：`obj_<物体>_<序号>.png`、`outline_<物体>_<序号>.png`、`sfx_<事件>_<序号>.wav`。
- 文档名带日期：`20261018_一页纸立项.md`。
- 版本号：`v0.1.0`（主.迭代.热修），构建包名 `dista-v0.1.0-{平台}-{yyyyMMdd}`。
